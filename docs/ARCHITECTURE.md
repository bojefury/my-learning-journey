# Архитектура

App Router использует Server Components по умолчанию; клиентская граница ограничена навигацией, каталогом, корзиной и формами. `src/lib/commerce.ts` не зависит от UI и покрывается unit-тестами. Доступ к PostgreSQL должен идти через repository/service layer, а Route Handlers — валидировать DTO через Zod и возвращать единый `{data}` / `{error:{code,message}}` формат. Критические операции заказа выполняются транзакционно: перечитать варианты и цены, зарезервировать остаток, применить промокод, создать заказ и историю статуса. Внешние системы доступны только через provider interfaces.
